# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## v1.0.0 - 2026-11-19

- Support PHP 8.6, with prebuilt binaries for Linux, macOS, and Windows. Installing on PHP 8.6
  requires PIE 1.5 or newer.
- Require Rust 1.95 or newer to build from source.
- Version the extension independently of anydoc. This release embeds anydoc 0.2.4.
